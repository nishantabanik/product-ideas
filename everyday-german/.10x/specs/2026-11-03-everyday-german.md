# Everyday German — first local website

The user approved implementation after reviewing the A1-first proposal. Brand: Everyday German. Folder: everyday-german. Audience: adults preparing for telc A1. English/German UI, lessons and explanations; all exam stimuli, prompts, choices, model answers and listening scripts remain German. Desktop and mobile support are required. Additional levels and courses are later modules.

First delivery: local responsive website with a dashboard, original four-skill exercise bank, short courses, vocabulary review, mistake review, device-local progress, and one timed four-skill practice exam. Objective answers are scored; productive skills use explicit self-review, never a fabricated official grade. No account, billing, live AI or public deployment in this release. A2 is shown honestly as planned.

All exercises are original drafts, awaiting qualified German teacher review before commercial launch. No competitor catalogue is imported. Browser-native German speech synthesis provides listening practice with a transcript fallback and an unavailable-voice message. This is adapted training, not an official telc test; picture-based tasks are represented with text alternatives.

Acceptance: language switching does not translate exam content; grading cannot occur before required answers; explanations appear after checking; progress survives reload; mock answers/drafts/timer survive reload; mock expiration submits; no forced account; touch/keyboard navigation; no horizontal mobile overflow. Browser storage failures must surface without breaking practice.

Implementation is staged in the writable current workspace and copied into the requested Desktop repository only as a new folder, preserving existing work. No commits, pushes or publication are authorized.
